APK kaise banayein (sabse aasan: GitHub se, PC pe kuch install nahi karna)
1. github.com pe free account banao -> New repository.
2. Is poore folder ki saari files (".github" folder samet) repository me upload karo.
3. Repository ke "Actions" tab me "Build APK" chalega (ya "Run workflow" dabao).
4. 3-5 minute baad run khol ke neeche "Artifacts" se UsefulVerbs-apk download karo.
5. Zip khol ke app-debug.apk phone me daalo aur install karo (Unknown sources allow karna padega).

Android Studio se: folder ko "Open" karo -> Build > Build APK(s).
